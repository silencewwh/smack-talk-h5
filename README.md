# Smack Talk H5

手机联机版：[打开 HTTP 游戏](http://118.31.175.232:3000/)，使用普通 `ws://118.31.175.232:3000/ws`，与 Android APK 共用房间。

GitHub Pages：[打开 HTTPS 页面](https://silencewwh.github.io/smack-talk-h5/)。此页面可单机与测试语音；点击创建/加入联机房间会进入 HTTP 联机版。建议新版 Chrome，横屏游玩。

## 游玩

- START → 单机练习 / 人机对战；选择角色、地图后开始。触屏按钮无需麦克风。
- HTTP 联机版使用触屏出招。手机浏览器禁止 HTTP 页面调用麦克风；APK 的原生离线语音不受此限制。
- 在 HTTPS 单机页面，OPTIONS 可选择中文/英文并测试麦克风。首次启用需下载中文约 44 MB 或英文约 41 MB 的 Vosk 本地语音模型，浏览器会缓存。识别在本机进行，声音不上传到识别服务器。
- 浏览器必须允许麦克风；存储被清理后语音包需重新下载。页面本身不承诺离线打开。
- 联机双方使用相同服务器，由房主创建房间，其他人输入 6 位房间码。最多 4 人。网络失败时仍可单机和触屏游玩。

## 版本说明

这是根据现有 Windows 游戏资源重建的浏览器实现，保留原画面资源与主要菜单布局，并适配手机屏幕；并非原 Unity 源工程的官方 WebGL 导出。部分特效与原版存在差异。浏览器版与 Android 重制版使用相同联机协议，原 Windows 版使用不同协议。

本仓库只保存网页发布文件，不含 APK、SSH 私钥、服务器配置、反编译源码或开发缓存。原游戏素材及音乐归各自权利人所有；游戏内 CREDITS 保留原制作人员与音乐署名。语音模型和引擎的第三方许可见 `voice/NOTICE.txt` 及相关许可证文件。
